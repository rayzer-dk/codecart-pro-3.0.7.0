# Imported workflow definitions

Original CI workflows from the previous CodeCart repository.
Stored here without activation to prevent old release/deploy jobs
from running before CodeCart PRO 3.0.7.0 integration testing.

Only explicitly reviewed workflows belong in .github/workflows.

The final CodeCart 3.0.6.1 packaging workflow is also preserved as `codecart-3061-production.yml` for historical reference. It must not be activated for 3.0.7.0.
