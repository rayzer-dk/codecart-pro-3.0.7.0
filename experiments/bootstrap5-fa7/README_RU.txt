CODECART PRO / EXPERIMENTAL COMPATIBILITY v0.2.1
Bootstrap 5.3.9 + Font Awesome 7.3.1 Free + CodeCart Bootstrap 3 Compatibility Layer
Исходная версия CodeCart: main, commit 9698479b62ce491d23e97706d5040cad9422302b. Изменений в main НЕТ.
Архив содержит автономные файлы библиотек, шрифты, адаптер и подготовленные полные копии header.twig.

admin/upload/ — готовая тестовая замена ТОЛЬКО админки.
storefront/upload/ — готовая тестовая замена ТОЛЬКО витрины (темы codecart/default).
Оба профиля полностью независимы; не требуется CDN, npm или компиляция.

УСТАНОВКА ТОЛЬКО НА ТЕСТОВОМ СТЕНДЕ
Сначала резервная копия. Сравнить исходные header.twig с версией основного коммита, указанного выше.
Для административной панели скопировать содержимое admin/upload/ поверх upload/ тестового клона.
Для витрины скопировать содержимое storefront/upload/ поверх upload/ тестового клона.
Никакие Bootstrap 3/Font Awesome 6 файлы автоматически не удаляются: изменены только подключения в подготовленных копиях header.twig.
Сбросить кэш Twig/OCMOD после подмены. Перед выпуском проверить регрессии.

НЕЛЬЗЯ напрямую применять на рабочем магазине: экспериментальный адаптер не гарантирует совместимость сторонних расширений, UniShop2, устаревших Bootstrap JS API и нестандартной разметки.
Особые риски: магазин/корзина/чекаут, модальные окна, динамические таблицы, datetimpicker, TinyMCE, карусели, мобильное меню, платежи, сторонние админ-модули.
Некоторые старые Glyphicons отображаются через Font Awesome 7 только для ограниченного набора. Нужна проверка классов.
Адаптер сохраняет старую сетку Bootstrap 3 (xs<768, sm>=768, md>=992, lg>=1200); отдельные тесты по ширинам 320/650/900/1050/1400px остаются обязательными.

ПРОВЕРКИ ПРИ СБОРКЕ
Проверены версии официальных исходных файлов, полнота 8 vendor-позиций в каждом профиле, наличие 3 полных header.twig и точные замены 3 подключений в них, порядок CSS-правил breakpoint.
Браузерный E2E и проверка реального магазина для v0.2.1 ещё НЕ выполнены.

ОТКАТ
Восстановить header.twig из резервной копии, очистить кэш; каталог codecart-bs5-compat удалить только после завершения проверки.
